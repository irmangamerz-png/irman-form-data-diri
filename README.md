# Form Data Diri — IRMAN (Railway)

## Deploy
1. Upload file `index.html`, `server.js`, dan `package.json` ke repository GitHub.
2. Buka https://railway.com/ dan login.
3. Pilih New Project → Deploy from GitHub Repo.
4. Pilih repository yang berisi file tadi dan tunggu deployment.
5. Di service Railway, buka Settings/Networking lalu pilih Generate Domain.
6. Buka domain `.up.railway.app` yang dibuat.

Railway menyediakan variabel PORT secara otomatis. Form ini menampilkan data di browser dan tidak menyimpan data ke database.
